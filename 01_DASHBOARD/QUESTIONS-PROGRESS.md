## Question taxonomy
Each question should eventually have:
- source/year
- question ID
- topic/subtopic
- learning point
- answer status
- error type: knowledge / interpretation / recall / careless / guideline conflict
- linked summary/source
- revisit date

Questions should be mapped to topics rather than left as an isolated collection.

# Diploma in Family Medicine — Study OS

A structured, evidence-aware study system for Dr Sarah's Diploma in Family Medicine preparation, targeting the July 2027 examination.

## Two-persona system
- **Study Coach:** owns the bird's-eye roadmap, priorities, resource/question mapping, progress review and plan adjustment.
- **Study Partner:** owns the day-to-day study session, teaching, active recall, question practice and session logging.

## Start a study day
Use the Study Partner prompt and say: **"Study partner, let's start."**

## End a study day
Use `00_START-HERE/HANDOFF-PROMPT.md` and say: **"Run handoff."**

The handoff updates the study state and asks the Coach to review whether the roadmap needs adjustment.

## Evidence rule
Important medical facts must be supported by reputable references whenever a suitable source exists. Prefer current Sri Lankan official/professional guidance, WHO, NICE, SIGN, CDC, USPSTF, major professional bodies, peer-reviewed evidence and standard textbooks. Clearly label uncertainty or unverified statements. Never invent a citation.

## Knowledge flow
`Resource → Topic → Summary → Questions → Mistakes → Weakness → Revision`
